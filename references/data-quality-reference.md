# 设备数据质量参考知识（指标 / 阈值 / 检测方法 / 归因）

> 供 data-quality-analyst 与主理人引用。若当前环境无法读取本文件，直接依据成员 MD 内的「速判规则」作答即可。

## 一、量化指标与分级阈值（可按业务调整，报告需注明所用阈值）

| 维度 | 指标公式 | 优 | 良 | 中 | 差 |
|------|----------|----|----|----|----|
| 完整性 | 完整率 = 实际收到条数 ÷ 应上报条数 × 100% | ≥98% | 95–98% | 90–95% | <90% |
| 时效性 | 及时率 = 延迟 ≤ 阈值（默认 5s，可调）的条数占比 | ≥98% | 95–98% | 90–95% | <90% |
| 准确性 | 异常率 = 异常条数 ÷ 总条数 × 100% | <0.5% | <1% | <3% | ≥3% |
| 一致性 | 冲突项数（单位/量纲/重复上报） | 0 | ≤2 | ≤5 | >5 |

## 二、异常检测方法速查

- **固定阈值法**：超出物模型量程（如温度 -40–85℃ 之外）→ 直接判异常
- **3σ 法**：对近似正态的缓变序列，|x-μ| > 3σ 判离群
- **IQR 法**：< Q1-1.5×IQR 或 > Q3+1.5×IQR 判离群（对非正态分布更稳健）
- **卡值检测**：传感器本应变化的量（温度/振动等）连续 ≥10 个周期读数完全相同 → 疑似卡值/死传感器
- **漂移检测**：滑动窗口均值单调偏移且超出标称精度带 → 疑似传感器漂移/未校准
- **乱序判定**：相邻报文时间戳倒挂（t[n+1] < t[n]）
- **重复上报**：同一设备同一内容在极短时间内（如 <1s）出现多条
- **时钟漂移**：设备时间戳与平台接收时间差随时间线性扩大

## 三、常见归因对照表

| 现象 | 高概率原因 | 验证方法 |
|------|-----------|----------|
| 每天固定时段缺失 | 设备定时重启/现场断电/休眠策略 | 对齐设备日志重启时间 |
| 随机丢包 | 网络信号弱/QoS 0 丢报 | 换 QoS 1 对比上报率 |
| 大批设备同时断档 | 平台重启/网关故障 | 查平台与网关可用性记录 |
| 单设备持续卡值 | 传感器硬件故障 | 下发读数指令交叉验证 |
| 读数超量程 | 解析错误/字节序错误/传感器损坏 | 查原始报文十六进制 |

## 四、进阶方法（专家级，单设备体检之外的三类深水区）

### 4.1 同类设备横向对比（Peer Comparison）— 找"沉默的异常设备"
单设备看曲线可能很正常，但和同型号同工况设备一比就露馅。

| 方法 | 做法 | 适用判断 |
|------|------|----------|
| 分位数排名 | 同一时段、同一型号设备按某指标排序，取 P5/P95 外设备 | 找出读数长期偏高/偏低的设备（系统性偏差） |
| 中位数偏离 | 设备值 − 同组中位数，超过组内 IQR 的 1.5 倍 | 组内一致性异常（安装位置/遮挡/未校准） |
| 波动性对比 | 计算各设备标准差，与组内中位数标准差比较 | 卡值（σ≈0）或抖动过大（接触不良） |
| 相关性对比 | 同一环境的设备读数应强相关，相关系数显著偏低者可疑 | 传感器失效或点位取错 |

### 4.2 多表交叉校验（Cross-table Validation）
单一数据源无法自证，需与其他表关联核对。

| 校验类型 | 关联对象 | 判定规则 |
|----------|----------|----------|
| 档案一致性 | 设备档案表 | 上报的 device_id 不在档案中 = 野设备；档案中设备长期无数据 = 僵尸设备 |
| 点位合法性 | 物模型定义 | 上报 identifier 未在物模型中定义 = 解析/配置不一致 |
| 量程校验 | 物模型 min/max | 越界值优先怀疑解析错误（字节序/单位）而非传感器损坏 |
| 状态与数据联动 | 设备在线状态表 | 离线状态仍有数据上报 = 通道串扰或状态表更新延迟 |
| 业务勾稽 | 用量表/工单/排产 | 产量为 0 但能耗持续 = 计量或工况异常（如空转、偷电） |
| 总分关系 | 总表 vs 分表 | 分表之和显著大于总表 = 计量错误或旁路（水务产销差常用） |
| 测点映射一致性 | 物模型测点表 | 上报 identifier 无对应测点、一测点被多属性共用 = 配置错误，会污染指标 |
| 质量码 | 测点质量码字段 | 质量码非"有效"占比高 = 采集/通讯问题，必须与真实异常分开统计，否则异常率虚高 |

### 4.3 时序对齐与降采样（Analysis Preprocessing）
数据频率不一致时直接算指标会得出错误结论。

- **对齐规则**：统一到同一时间栅格（如 5 分钟），用 `最近值保持`（前值填充）或 `区间聚合`（mean/max/min）
- **时区/时钟**：确认设备、平台、报表三方时区一致（尤其跨时区项目与夏令时）
- **降采样**：长周期分析用均值+极值组合（只取均值会掩盖尖峰异常）；计数类指标用求和而非均值
- **缺口处理**：短缺口（≤2 个周期）可插值；长缺口必须标记为缺失，**禁止插值掩盖断传**
- **聚合口径**：明确"日均值"是按有效数据点平均还是按时间加权，报告中需注明
